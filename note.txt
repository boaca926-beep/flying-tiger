Email: Fix the Domain and Sender Identity

The single most important fix is to stop using Resend's test mode.
Verify Your Domain: You must add and verify at least one domain you own in the Resend dashboard to send emails to real customers. 
It's a best practice to use a subdomain (e.g., updates.yourdomain.com) instead of the root domain for sending emails.
Update RESEND_FROM: Once verified, change the RESEND_FROM environment variable to use an address on that domain (e.g., Asian Food Market <orders@yourdomain.com>).
Disable Test Mode: In your app.py, set TEST_RECIPIENT = None. This allows the code to send to the real address the user typed in the form.
